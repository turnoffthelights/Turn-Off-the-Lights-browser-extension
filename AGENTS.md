# AGENTS.md

Turn Off the Lights — a Manifest V3 browser extension (GPL-2.0) plus its
platform wrapper apps. The web extension lives in `src/` and is built
per-browser with gulp; the Xcode project wraps it as a Safari Web
Extension for iOS, macOS, and visionOS.

## Repository layout

- `src/` — extension source: `manifests/` (per-browser + `common.json`),
  `constants/<browser>/constants.js`, `scripts/`, `styles/`, `images/`,
  `_locales/`, `options.html`, `popup.html`, `palette.html`, `schema.json`
- `dist/<browser>/` — gulp build output (gitignored per-browser folders)
- `xcode/Turn-Off-the-Lights-Safari-extension/` — the Safari app:
  `iOS/` and `macOS/` SwiftUI app code, `Shared (App)/` shared Swift,
  `Shared (Extension)/Resources/` the injected web-extension payload
  (generated by `gulp safari` — do not edit it directly), and the
  `SafariWebExtensionHandler`
- `android-app/` — Android wrapper app (Gradle)
- `xcode-skills/` — Apple Xcode skills exported via `xcrun agent skills
  export`; reference material, not part of the build

## Build & verify

Extension (Node + gulp):

- `npm install` — install dev dependencies
- `npm run lint` — ESLint over `src/**/*.js` (config: `eslint.config.mjs`)
- `npm run chrome` / `firefox` / `opera` / `edge` / `whale` / `yandex` /
  `samsung` — build one browser target into `dist/<browser>/`
- `npm run safari` — builds into `xcode/.../Shared (Extension)/Resources`
  so the Safari app embeds the fresh extension; run this before Xcode
  builds after changing `src/`
- `npm run browserzip` — build every browser and produce store zips

Safari app (verified working):

```sh
xcodebuild -project "xcode/Turn-Off-the-Lights-Safari-extension/Turn Off the Lights for Safari.xcodeproj" \
  -scheme "Turn Off the Lights for Safari iOS" -configuration Debug \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Schemes: `Turn Off the Lights for Safari iOS`,
`Turn Off the Lights for Safari macOS`, plus the `TOtL-iOS-test` /
`TOtL-iOS-UITest` targets (currently stub `testExample` placeholders —
no real test suite exists).

## Conventions

- JS style (enforced by ESLint): tabs for indentation, double quotes,
  no space before `(` in function declarations/calls, no space inside
  `{`/`}` or `[`/`]`, `keyword(){}` compact spacing. Match `src/` files.
- Version number lives only in `package.json`; the gulp build injects it
  into each generated `manifest.json`. Bump it there, not in
  `src/manifests/`.
- iOS app is pure SwiftUI (`@main` App + `WindowGroup`, no AppDelegate).
  It was audited for iPhone Duo / resizable-scene readiness (Nov 2026):
  keep it free of `UIScreen.main`, `interfaceOrientation`,
  `userInterfaceIdiom`, and bare `ignoresSafeArea()`/`edges: .all` on
  readable content — scope edge-ignores to the edges content must reach,
  and let background fills own the full-bleed behavior.
- Edge-to-edge layers that are legitimately full bleed (gradients,
  scrims, media surfaces) may keep `ignoresSafeArea(.all)`; readable or
  interactive content should not.
